# 의도: create_page (새 페이지/화면 생성)

새로운 페이지·화면·라우트를 처음부터 만들어 달라는 요청. 슬롯(페이지명·도메인)은 별도 추출하므로
여기서는 "새로 만든다"는 의미만 다양한 표현으로 모은다.

- 상품 목록 화면 만들어줘
- 주문 상세 페이지를 새로 생성해줘
- 회원 관리 화면 하나 추가해줘
- catalog 도메인에 ProductListPage 만들어줘
- 새 대시보드 페이지 만들어줘
- 결제 내역 화면을 만들어 주세요
- 공지사항 등록 폼 페이지 생성해줘
- 게시판 목록 화면 새로 만들어줘
- create a new settings page
- add a profile page
- 통계 화면 하나 새로 짜줘
- 신규 입고 등록 페이지 만들어줘
- 사용자 검색 화면 만들어줘
- 카테고리 관리 페이지를 추가하고 싶어
- InventoryDetailPage 페이지 생성
- 로그인 화면 만들어줘
- 새로운 리포트 화면 구성해줘
- 예약 목록 페이지 만들어줘
- 비어있는 페이지 하나 만들어줘
- 쿠폰 발급 화면 새로 만들어 줘
- 빌링 도메인에 인보이스 화면 만들어줘
- make a dashboard screen from scratch
- 알림 설정 페이지 추가해줘
- 새 화면 스캐폴딩 해줘
