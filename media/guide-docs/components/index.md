# UI 컴포넌트

`react-app-scaffold`에서 제공하는 UI 컴포넌트입니다. 아래 목록에서 항목을 선택하면 각 컴포넌트 상세 페이지로 이동합니다.

## 컴포넌트 목록

- **[Accordion](./ui/accordion-component)** — 접었다 펼 수 있는 아코디언 컴포넌트
- **[Alert](./ui/alert-component)** — 정보·경고를 표시하는 알림 컴포넌트
- **[Avatar](./ui/avatar-component)** — 프로필 이미지를 보여주고 실패 시 이니셜로 대체하는 아바타 컴포넌트
- **[Badge](./ui/badge-component)** — 상태·라벨·개수 등을 짧게 강조하는 배지 컴포넌트
- **[Breadcrumb](./ui/breadcrumb-component)** — 현재 화면의 계층 위치를 한 줄로 보여주는 경로 탐색 컴포넌트
- **[Button](./ui/button-component)** — 기본 버튼 컴포넌트
- **[Button Group](./ui/button-group-component)** — 여러 버튼을 하나의 그룹으로 묶는 컴포넌트
- **[Calendar](./ui/calendar-component)** — 날짜 또는 기간을 선택하는 캘린더 컴포넌트
- **[Card](./ui/card-component)** — 하나의 주제로 묶인 정보를 한 덩어리로 보여주는 카드 컴포넌트
- **[Carousel](./ui/carousel-component)** — 슬라이드를 넘기며 보여주는 캐러셀 컴포넌트
- **[Checkbox](./ui/checkbox-component)** — 켜짐·꺼짐을 전환하는 체크박스 컴포넌트
- **[Combobox](./ui/combobox-component)** — 입력과 제안 목록으로 항목을 고르는 콤보박스 컴포넌트
- **[Dialog](./ui/dialog-component)** — 모달 형태로 확인·알림·짧은 입력을 받는 대화상자 컴포넌트
- **[Drawer](./ui/drawer-component)** — 화면 가장자리에서 밀려 나오는 시트(바텀시트·사이드시트) 컴포넌트
- **[Input](./ui/input-component)** — 폼·데이터 입력용 단일 라인 텍스트 입력 컴포넌트
- **[InputGroup](./ui/inputgroup-component)** — 입력창에 아이콘·고정 텍스트·버튼을 한 테두리로 묶는 컴포넌트
- **[Native Select](./ui/native-select-component)** — 브라우저 기본 `<select>` 기반의 가벼운 선택 컴포넌트
- **[Pagination](./ui/pagination-component)** — 긴 목록을 페이지 단위로 이동하는 페이지네이션 컴포넌트
- **[Progress](./ui/progress-component)** — 완료 비율을 가로 막대로 보여주는 진행률 컴포넌트
- **[RadioGroup](./ui/radio-group-component)** — 여러 선택지 중 하나만 고르는 라디오 그룹 컴포넌트
- **[Select](./ui/select-component)** — 드롭다운 목록에서 하나를 고르는 셀렉트 컴포넌트
- **[Skeleton](./ui/skeleton-component)** — 로딩 중 콘텐츠 자리를 미리 잡아주는 플레이스홀더 컴포넌트
- **[Slider](./ui/slider-component)** — 손잡이를 끌어 숫자·범위 값을 고르는 슬라이더 컴포넌트
- **[SmartTable](./ui/smart-table-component)** — 정렬·페이징·검색·엑셀 내보내기까지 포함한 고수준 데이터 그리드
- **[Spinner](./ui/spinner-component)** — 작업이 진행 중임을 알리는 회전 로딩 인디케이터 컴포넌트
- **[Switch](./ui/switch-component)** — 켜짐·꺼짐을 즉시 전환하는 스위치 컴포넌트
- **[Table](./ui/table-component)** — 마크업을 직접 제어하는 저수준 표(table) 프리미티브
- **[Tabs](./ui/tabs-component)** — 같은 자리에서 여러 패널을 전환해 보여주는 탭 컴포넌트
- **[Textarea](./ui/textarea-component)** — 줄바꿈이 포함된 긴 문장을 입력받는 여러 줄 텍스트 입력 컴포넌트
- **[Toast](./ui/toast-component)** — 작업 결과·오류 등을 짧게 알리는 토스트 컴포넌트
- **[Toggle](./ui/toggle-component)** — 눌린 상태가 유지되는 토글 버튼 · 세그먼트 컨트롤 컴포넌트
- **[Tooltip](./ui/tooltip-component)** — 마우스 오버·포커스 시 짧은 보조 설명을 띄우는 말풍선 컴포넌트
